# AI / ML Track
**In one sentence.** For those building learning systems: start from the math, move
through classical ML and deep learning to RL, LLMs, and the systems that train them.
Prerequisite: [[core-spine]] plus solid math.

## The path
1. **Math foundations** — [[matrices-and-linear-maps]],
   [[eigenvalues-and-eigenvectors]], [[svd-and-pca]]; probability via
   [[random-variables-expectation]] and [[bayes-theorem-and-inference]].
2. **Classical ML** — [[machine-learning-basics]], [[gradient-descent]],
   [[linear-models-logistic-regression-and-glms]],
   [[unsupervised-learning-em-and-mixture-models]] (CS229).
3. **Deep learning** — [[deep-learning-basics]], [[neural-network-training]],
   [[convolutional-neural-networks]], [[recurrent-neural-networks-and-lstms]],
   [[transformers-and-attention]] (CS231N / CS224N).
4. **Reinforcement learning** — [[markov-decision-processes]],
   [[reinforcement-learning-basics]], [[deep-reinforcement-learning]] (CS285).
5. **Learning theory & PGMs** — [[statistical-learning-theory]],
   [[probabilistic-graphical-models]].
6. **ML systems** — [[automatic-differentiation]],
   [[parallel-architectures-simd-gpu]] (10-714).
7. **LLMs & safety** — [[large-language-models]],
   [[self-supervised-and-contrastive-learning]], [[fairness-in-machine-learning]],
   [[interpretability-and-explainability]] (CS336 / CS324).
