# Berkeley CS61B

## What it is
Weeks 1–4: Java, IntLists → SLList → DLList → ALists, testing, generics, inheritance, iterators,
asymptotics; 5: disjoint sets (quick find → quick union → weighted → path compression), ADTs,
BSTs; 6: B-trees, red-black trees; 7: hashing; 8: heaps and PQs, tries; 9–10: graph traversals,
topological sort, shortest paths (Dijkstra, A*), MSTs (Prim, Kruskal); 11: range searching, k-d
trees, multidimensional data; 12–13: sorting (selection, heapsort, mergesort, insertion, quicksort,
sorting lower bound, radix sorts, sorting and data structures), compression (Huffman, LZW),
complexity (P/NP intro). Projects: Deques, NGordnet, Gitlet (a Git clone — a great capstone for
[[git-data-model]]), BYOW (world generation).
**CS106B**: C++ ADTs, recursion, backtracking, big-O, linked lists, BSTs, hashing, graphs, huffman.
**6.006**: sequence/set interfaces, arrays vs linked lists, sorting (n log n), hashing (universal),
comparison model lower bound, DAAs/AVL trees, heaps, BFS/DFS, weighted shortest paths, DP.

## What it adds
The best-scaffolded path through [[union-find]], [[balanced-search-trees]], [[hash-tables]],
[[heaps-and-priority-queues]], [[tries]], and [[graph-representations]]; 6.006 supplies the proofs
and interface-first thinking ([[abstract-data-types-and-rep-invariants]]).
