# Think Python (3rd ed.)

## What it is
Nineteen short chapters, one idea each, all runnable as notebooks. Chapters: programming as a way of
thinking; variables and statements; functions; functions and interfaces (incremental development);
conditionals and recursion; return values; iteration and search; strings and regular expressions;
lists; dictionaries; tuples; text analysis and generation (Markov text); files and databases; classes
and functions; classes and methods; classes and objects; inheritance; Python extras. Every chapter ends
with a **Debugging** section and a glossary.

## Key ideas → pages
- **Incremental development**: add a few lines, run, print intermediate values; scaffolding code you
  later remove — [[design-recipe]], [[debugging]].
- The debugging appendix: syntax vs runtime vs semantic errors; "reading, running, ruminating,
  retreating"; if a fix doesn't work, revert — [[debugging]].
- Recursion via stack diagrams; infinite recursion and the base case — [[recursion-and-iteration]].
- Dictionaries as the workhorse (memoization via dict, counting, inverting) — [[hash-tables]].

## What it adds
Gentlest of the §2.1 texts; its debugging discipline is the one thing not in [[sicp]] or [[composing-programs]].
