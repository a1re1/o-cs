# CMU 15-445 and related courses

## What it is
Lecture sequence (Fall 2024): 01 relational model & algebra; 02 modern SQL (window functions,
CTEs, lateral joins); 03–04 database storage (disk-oriented architecture, slotted pages, tuple
layout, log-structured storage, index-organized storage, large values); 05 storage models
(n-ary vs decomposition vs hybrid — row/column/PAX) and compression; 06 memory management
(buffer pool, replacement policies LRU-K/CLOCK, prefetching, why not mmap); 07 hash tables
(static/dynamic, linear probing, cuckoo, extendible/linear hashing); 08–09 indexes & filters
(B+trees, design choices, Bloom filters, skip lists, tries/radix trees); 10 index concurrency
control (latch crabbing); 11 sorting & aggregation (external merge sort); 12 joins (nested loop,
sort-merge, hash join, partitioned hash); 13–14 query execution (processing models, access
methods, expression evaluation, parallel/intra-query parallelism); 15 query planning &
optimization (heuristics, cost-based search, cardinality estimation); 16 concurrency control
theory (serializability, conflicts); 17 2PL (strict 2PL, deadlocks, hierarchical locking); 18
timestamp ordering and OCC; 19 MVCC; 20 logging (WAL, steal/force); 21 recovery (ARIES); 22–24
distributed databases (OLTP: 2PC, replication; OLAP: execution models, cloud systems); 25
potpourri. Textbook: Silberschatz. Projects: C++ primer; buffer pool manager; B+tree (or
extendible hash) index; query execution + optimizer rules; concurrency control (MVCC).
**15-721**: in-memory engines, latch-free structures, compilation, vectorization, HTAP.
**CS186**: SQL, disks and files, B+trees, buffer management, sorting/hashing, joins, query
optimization, transactions, recovery, parallel query processing, distributed transactions;
project in Java (RookieDB). **CS145/Stanford DB MOOC**: relational algebra, SQL, XML/JSON,
constraints, views, indexes, transactions, recursion in SQL. **6.5830**: Red Book papers.
