# Essence of Linear Algebra (3Blue1Brown)

## What it is
A visual prequel to any linear algebra course (~2.5 hours total). Episodes: vectors; linear
combinations, span, basis; linear transformations and matrices; matrix multiplication as composition;
3D transforms; the determinant; inverse matrices, column space, null space; nonsquare matrices; dot
products and duality; cross products; Cramer's rule; change of basis; eigenvectors and eigenvalues;
a quick trick for 2×2 eigenvalues; abstract vector spaces.

## Key intuitions worth carrying
- A matrix *is* where the basis vectors land; the columns are the images of e₁, e₂, … ([[matrices-and-linear-maps]]).
- det = signed factor by which area/volume scales; det = 0 ⇔ the map squashes space, so no inverse
  ([[gaussian-elimination-lu]]).
- Eigenvectors are the directions the transformation only stretches ([[eigenvalues-and-eigenvectors]]).
- Change of basis = "translate into their language, apply the transform, translate back" (P⁻¹AP).
- Dot product with a vector = a linear map to 1-D (duality), which is why projections are inner products
  ([[orthogonality-and-projections]]).

## What it adds
Intuition only — no algorithms, no proofs, no SVD (a later video covers it briefly). Watch first, then
read [[strang-18-06]].
